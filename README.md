# Proyecto Final — Control Inteligente | Equipo 3 · Péndulo 2

Portafolio Jekyll/Just the Docs para documentar el control inteligente del péndulo invertido Quanser QUBE-Servo 3, conservando la identidad visual y navegación de la Evaluación I.

**Sitio (tras publicarlo):** https://vmolvera.github.io/Proyecto_Final_Control_Inteligente/

**Código técnico:** https://github.com/sebastiux/cubeservoquansecontrol

## Publicación

1. Crear en GitHub un repositorio público `Proyecto_Final_Control_Inteligente` en la cuenta `vmolvera`, sin README inicial.
2. Subir el **contenido de esta carpeta** a la raíz del nuevo repositorio (no subir el ZIP como único archivo).
3. En Settings → Pages, elegir **Deploy from a branch**, `main`, `/ (root)`, y guardar.
4. Verificar el resultado en Actions y la URL del sitio.

## Ejecutar localmente (opcional)

```bash
bundle install
bundle exec jekyll serve
```
